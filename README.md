# صبّارة AI — الموقع الرسمي | SABBARAH AI — Official Site

موقع ثابت (HTML / CSS / JavaScript صرف) يعمل مباشرة على GitHub Pages بدون أي خطوة بناء.
A static site (plain HTML / CSS / vanilla JS) that runs directly on GitHub Pages with no build step.

---

## البنية | Architecture

الموقع مبني على تصنيف واحد يقوم على **طريقة الشراء والتسليم**، وليس على نوع العميل:

| القسم | Section | الوصف |
|---|---|---|
| الحلول المخصصة | Custom Solutions | نطاق وسعر يعتمدان على عمليات العميل — «يبدأ من» |
| المنتجات الجاهزة | Ready Products | نطاق وتسليم وسعر ثابت ومعلن |

> تم حذف تصنيف «للأعمال / للأفراد» ومفتاح التبديل الخاص به بالكامل.

## نظام اللغة | Localization

العربية هي المصدر ومكتوبة داخل HTML مباشرة. الإنجليزية تُكتب بجانبها في سمة `data-en`:

```html
<h2 data-en="Custom Solutions">الحلول المخصصة</h2>
<meta name="description" content="…عربي…" data-en-content="…English…">
<button aria-label="فتح القائمة" data-en-aria-label="Open menu">
```

- السمات المدعومة: `data-en`, `data-en-content`, `data-en-aria-label`, `data-en-title`, `data-en-placeholder`, `data-en-alt`.
- النصوص التي يولّدها الجافاسكربت (الفحص، العرض الحي) في قاموس `SB.STRINGS` داخل `js/i18n.js`.
- اللغة تُحفظ في `localStorage` تحت المفتاح `sabbarah-lang` وتبقى ثابتة بين الصفحات.
- التبديل يضبط `lang` و `dir` على `<html>` تلقائيًا (`ar/rtl` ↔ `en/ltr`).

**لإضافة نص جديد:** اكتب العربية داخل العنصر وأضف `data-en` بالإنجليزية. لا يوجد ملف ترجمة منفصل يحتاج مزامنة.

## التشغيل محليًا | Run locally

```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```

يجب استخدام خادم محلي (وليس فتح الملف مباشرة) حتى يعمل `localStorage` وتحميل الملفات بشكل صحيح.

---

## النشر | Deployment

ارفع محتويات هذا المجلد إلى فرع النشر في مستودع GitHub Pages. لا توجد خطوة بناء،
ولا اعتماديات، ولا متغيرات بيئة. ملف `CNAME` يحافظ على النطاق المخصص.
